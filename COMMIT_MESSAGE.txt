## 🐛 Fix: Tab-Abuse Rule - Timestamp Conversion Bug

### Vấn đề
Backend crash với lỗi "Unable to access jarfile" và tab-abuse rule không tạo incidents.

### Nguyên nhân
1. Docker image chưa được build
2. `IngestService.java` line 96 sử dụng sai `Instant.ofEpochSecond(item.ts)` 
   - API `ts` field là **milliseconds** (13 digits: 1763298216113)
   - Method `ofEpochSecond()` expect **seconds**
   - Dẫn đến timestamp sai 1000 lần → Redis keys sai → Rule không trigger

### Giải pháp
1. Build Docker image: `docker-compose up --build`
2. Sửa IngestService.java line 96:
   ```java
   // Before
   ruleService.evaluateTabSwitch(sessionId, Instant.ofEpochSecond(item.ts));
   
   // After
   ruleService.evaluateTabSwitch(sessionId, Instant.ofEpochMilli(item.ts));
   ```
